Instalação

Três formas de começar com VeloPHP.

Pré-requisitos

  • PHP ≥ 8.2
  • PDO MySQL
  • Composer

Método 1: Composer create-project

composer create-project velo/php meu-app
cd meu-app
cp .env.example .env
php velo serve

Método 2: Instalador interativo

php -r "copy('https://raw.githubusercontent.com/ens-Emilio/VeloPHP/main/installer/create.php', 'create-velophp');" && php create-velophp

Método 3: GitHub clone

git clone https://github.com/ens-Emilio/VeloPHP.git meu-app
cd meu-app
composer install
cp .env.example .env
php velo serve

Configuração do ambiente

Edite o arquivo .env com suas configurações:

DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=velophp
DB_USERNAME=root
DB_PASSWORD=

Verifique a instalação

php velo test
php velo route:list
php velo db:test
