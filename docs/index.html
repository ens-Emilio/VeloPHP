Por que VeloPHP?

🚀

Rápido

Sem overhead desnecessário. Roteador leve, container com auto-resolução, zero magic strings.

📦

Completo

Migrations, seeders, schema builder, relacionamentos, soft deletes, validação, views, cache, auth.

🔧

CLI Poderoso

25+ comandos: serve, make:*, migrate, route:list e mais.

🛡️

Seguro

CSRF, security headers, rate limiting, CORS configurável, SQL injection prevention via PDO bindings.

🧩

Modular

Service providers, middleware pipeline, eventos, container PSR-11 com auto-resolução via Reflection.

📊

Testado

87+ testes (Pest), PHPStan level, Pint style, CI em 3 versões do PHP.

3 passos para começar

1. Instale

composer create-project velo/php meu-app

2. Configure

cp .env.example .env e edite suas credenciais

3. Sirva

php velo serve e acesse localhost:8000
