Quickstart

Crie sua primeira rota, controller e migration em 5 minutos.

1. Rota simples

Edite routes/web.php:

<?php

$router->get('/', function () {
    return response()->json(['message' => 'Olá, VeloPHP!']);
});

2. Controller

php velo make:controller UserController

Edite app/Controllers/UserController.php:

public function index(): array
{
    return ['users' => []]; // Ou DB::table('users')->get()
}

Registre a rota:

$router->get('/users', [UserController::class, 'index']);

3. Migration

php velo make:migration create_users_table

Edite o arquivo gerado em database/migrations/:

public function up(): void
{
    Schema::create('users', function (Blueprint $table) {
        $table->id();
        $table->string('name');
        $table->string('email')->unique();
        $table->timestamps();
    });
}
php velo migrate

4. Próximos passos

  • Referência de comandos CLI
  • Explore os arquivos em routes/ e config/
  • Crie models com php velo make:model
