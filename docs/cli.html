CLI Reference

Todos os comandos disponíveis no VeloPHP.

Servidor

ComandoDescrição
php velo serveInicia servidor de desenvolvimento

Database / Migrations

ComandoDescrição
php velo migrateExecuta migrations pendentes
php velo migrate --pretendMostra SQL sem executar
php velo migrate:rollbackReverte último batch
php velo migrate:resetReverte todas as migrations
php velo migrate:freshDropa tabelas e executa do zero
php velo migrate:fresh --seedFresh + seed
php velo db:seedExecuta seeders
php velo db:seed --class=UserSeederExecuta seeder específico
php velo db:testTesta conexão com banco

Make (Geradores)

ComandoDescrição
php velo make:migration create_users_tableCria migration
php velo make:seeder UserSeederCria seeder
php velo make:controller UserControllerCria controller
php velo make:model UserCria model
php velo make:middleware AuthMiddlewareCria middleware
php velo make:provider AppServiceProviderCria service provider
php velo make:repository UserRepositoryCria repository
php velo make:listener SendEmailCria event listener
php velo make:view indexCria view

Routes

ComandoDescrição
php velo route:listLista todas as rotas
php velo route:cacheCache de rotas
php velo route:clearLimpa cache de rotas

Cache

ComandoDescrição
php velo cache:clearLimpa cache

Quality

ComandoDescrição
php velo testExecuta testes (Pest)
php velo lintVerifica estilo (Pint)
php velo analyseAnálise estática (PHPStan)
